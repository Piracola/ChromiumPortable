Helium とは

imputnet がメンテナンスする Helium は、ブラウザーの「ユーザーのためにならない部分」を取り除く Chromium フォークです。広告を既定でブロックし、Google テレメトリとバックグラウンド報告を削り、プロモーションやアカウント誘導を削ぎつつ、Chromium エンジンと拡張互換性は完全に保ちます。

Chrome の性能と拡張は好きだけれど Google スタックごと欲しくないなら、Helium は有力な選択肢です。本リポジトリはさらに Chrome++ のポータブル化を重ね、システムインストールには一切触れないようにしています。

Stable と Preview

ファイル名に Preview が付かないものが stable で、日常はこちら。Preview は上游の最新プリリリースを追う早期検証用で、安定性は保証されません。

両方とも同じ GitHub Release にあります。stable だけ更新された場合も、パイプラインが前回の preview アーカイブを新しい Release に残すため、常に最新リリースから両方を取得できます。

使い方

  1. 必要なアーカイブを Releases からダウンロード。
  2. 任意の場所に展開。
  3. 開始.bat をダブルクリック、または Helium\chrome.exe を実行。
  4. プロファイルとキャッシュは Helium\Data と Helium\Cache に作られます。

更新方法

ブラウザーを終了し、旧 Helium の Data をバックアップしてから旧フォルダーを削除、新版を展開し Data を戻してください。本リポジトリは上游を毎日追跡し、新版を自動公開します。

ダウンロードを検証する

各 Release にはアーカイブごとの SHA256 が記載されています。ダウンロード後に PowerShell で 1 コマンド実行し、一致すればビルド出力とバイト単位で同一です。

certutil -hashfile .\Helium_version_date.7z SHA256

ビルドログは GitHub Actions で公開されており、その実行が作ったアーカイブであることを確認できます。

すぐに使える Chrome++ 機能

Bush2021/chrome_plus を統合。以下は既定で有効で、chrome++.ini で調整・無効化できます。

  • プロファイルとキャッシュはアプリ隣の Data / Cache フォルダー
  • タブをダブルクリックで閉じる（最後のタブは残す）
  • タブバーにホイール操作でタブ切り替え
  • アドレスバーの文字列とブックマークを新しい前面タブで開く
  • Windows ログインパスワードなしで保存済みパスワードを表示
  • 右クリックで閉じる・ボスキー・翻訳ショートカット・キー割り当て・起動/終了フック（既定オフ）

よくある質問

公式のインストーラー版と何が違いますか？

エンジンも機能も同じで、どちらも公式パッケージ由来です。ポータブル版はインストールを省き、レジストリ書き込みやバックグラウンド更新も行いません。プロファイルとキャッシュはアプリ隣の Data / Cache に置かれ、フォルダーごと移動でき、削除すればクリーンに消えます。

自動更新されますか？

されません。ポータブル版はシステム更新サービスを登録しません。本プロジェクトは GitHub Actions で公式チャネルを毎日確認し、新版があれば Releases に公開します。手動でダウンロードして上書きし、Data を残せばデータも残ります。

ダウンロードが改ざんされていないか確認するには？

各 Release 本文にファイル名・サイズ・SHA256 を記載しています。ダウンロード後に PowerShell で certutil -hashfile ファイル名.7z SHA256 を実行し、値を照合してください。ビルドログも Actions で公開しており、その実行が作ったアーカイブであることを確認できます。

データはどこにありますか？別 PC へ移すには？

ブラウザーの隣の Data フォルダー（キャッシュは Cache）です。フォルダー全体をコピーすれば、ブックマーク・パスワード・拡張・ログイン状態もそのまま移ります。

ウイルス対策が検出しました。安全ですか？

Chrome++ は version.dll をブラウザーに注入（DLL サイドローディング）してポータブル化するため、ヒューリスティックで誤検知されることがあります。ビルドスクリプト・ワークフロー・ログは GitHub で公開、アーカイブは GitHub Actions が SHA256 付きで出荷します。必要ならソースからローカルビルドも可能です。

32 ビットや Windows 7 に対応していますか？

Windows x64 のみ公開しています。システム要件は上游ブラウザーに従い、各社 Windows 7 / 8.1 のサポートを終了済みです。Windows 10 または 11 を使ってください。

インストール済みブラウザーと併用できますか？

できます。ポータブル版は独立したプロファイルディレクトリを使うため、インストール版と干渉せず同時に動かせます。

有料ですか？広告は付きますか？

どちらもありません。パイプラインは展開・Chrome++ 統合・注入・圧縮のみで、ホームページ変更も事前インストール拡張もプロモ同梱もしません。ソースは MIT ライセンスで完全に公開されています。

Windows SmartScreen や Defender が警告を出します。安全ですか？

SmartScreen の評判はファイル単位で時間とともに蓄積されるため、GitHub Release 上の新しい資産はしばしば「不明」と表示されます。また Chrome++ は version.dll を注入する（DLL サイドローディング）ため、Defender のヒューリスティックに反応されることがあります。ビルドスクリプト・ワークフロー・完全なログはすべて GitHub で公開されており、アーカイブは GitHub Actions が SHA256 付きで出荷します。必要ならソースからローカルでビルドできます。不安なら使わないでください。

Google や Microsoft にサインインして同期できますか？

できます。プロファイルはポータブル版の Data フォルダーに置かれ、ブックマーク・パスワード・拡張機能の同期はインストール版と同じように動きます。共有 PC に置いたポータブルなプロファイルには認証情報も入るため、他の機密データと同じようにフォルダー全体を扱ってください。

USB メモリや別の PC でも動きますか？

動きます。書き込み可能な場所（USB メモリ、外付けディスク、別の PC）に解凍すれば、ユーザーデータはアプリの隣に残ります。リムーバブルメディア上の実行ファイルをブロックするセキュリティ製品もあります。その場合はフォルダーをローカルディスクにコピーしてから起動してください。

Chromium 系ブラウザーのオープンソース自動ポータブルビルド。ブラウザー本体の権利は各ベンダーにあり、ビルドスクリプトは MIT ライセンスです。
