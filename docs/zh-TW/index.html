為什麼值得用這一份

網路上的「綠色版」大多來路不明。這個專案的每一步都能被你自己覆核。

安裝檔直接來自官方

Chrome 走 Google Omaha 更新 API，Edge 走微軟 CDP 介面，Helium 取上游 GitHub Release，沒有第三方中轉下載。

雜湊對得上才繼續

上游給出的 SHA256 會先被記錄，下載時邊下邊算，對不上立刻中止建置，絕不會把一個來路可疑的安裝檔打進壓縮檔。

注入結果會被驗證

打包完成後會解析 PE 匯入表，確認 Chrome++ 的 version.dll 真的以相對路徑注入成功，而不是「看起來成功了」。

發佈前真的跑一遍

解壓縮成品壓縮檔、啟動瀏覽器、確認使用者資料目錄確實落在解壓縮目錄內——可攜性是被驗證過的，不是宣稱的。

沒有閉源環節

建置腳本、工作流程、每一次建置的完整日誌都在 GitHub 上公開，壓縮檔的 SHA256 寫在 Release 內文裡，可自行比對。

不夾帶任何東西

只做解包、整合 Chrome++、注入、壓縮四件事。不改首頁、不裝擴充、不加推廣，原始碼可逐行核對。

開箱即用的增強

整合 Bush2021/chrome_plus，以下功能預設啟用，都可以在 chrome++.ini 裡改或關掉。

  • 使用者資料與快取存放在程式同級的 Data、Cache 資料夾
  • 連按兩下關閉分頁，並保留最後一個分頁
  • 滑鼠停留在標籤列時用滾輪切換分頁
  • 網址列內容與書籤在新建前景分頁中開啟
  • 免驗證系統登入密碼即可檢視已儲存的密碼
  • 右鍵關閉分頁、老闆鍵、翻譯快速鍵、按鍵映射、啟動與結束鉤子等擴充能力（預設未啟用）

常見問題

可攜版和官方安裝版有什麼差別？

核心和功能完全一樣，都來自官方安裝檔。差別是可攜版不執行安裝：不寫登錄檔、不註冊背景更新服務，使用者資料與快取保存在程式同級的 Data、Cache 資料夾裡。整個目錄可以隨意搬動或拷進 USB 隨身碟，刪除資料夾就等於解除安裝乾淨。

會自動更新嗎？

不會。可攜版不註冊系統更新服務，所以不會在背景自己升級。本專案每天用 GitHub Actions 檢查官方是否發佈新版本，有就自動建置並發佈到 Releases，你手動下載覆蓋即可，更新時保留 Data 目錄就能留住全部資料。

怎麼確認下載的檔案沒被竄改？

每個 Release 的內文裡都有一張校驗表，列出每個壓縮檔的檔名、大小和 SHA256。下載後在 PowerShell 裡執行 certutil -hashfile 檔名.7z SHA256，把輸出和表裡的值比對一致即可。建置全過程的日誌也公開在 Actions 裡，可以核對壓縮檔確實由那次建置產出。

使用者資料保存在哪裡？換電腦怎麼遷移？

保存在瀏覽器資料夾同級的 Data 目錄（快取在 Cache 目錄）。遷移時把整個資料夾拷到新電腦就行，書籤、密碼、擴充、登入狀態都會跟著走，不需要重新設定。

防毒軟體回報病毒怎麼辦？

Chrome++ 的可攜化依靠把 version.dll 注入到瀏覽器行程來實作，這屬於 DLL 側載技術，部分安全軟體會因此產生啟發式誤報。本專案的建置腳本、工作流程和每次建置的完整日誌都在 GitHub 上公開，壓縮檔由 GitHub Actions 直接產出並附帶 SHA256，你可以自行核對來源；介意的話也可以依倉庫說明在本機自行建置。

支援 32 位元系統嗎？支援 Windows 7 嗎？

只提供 Windows x64 版本，沒有 32 位元建置。系統需求跟隨上游瀏覽器本身，目前上游各瀏覽器均已停止支援 Windows 7 / 8.1，建議在 Windows 10 或 Windows 11 上使用。

可以和已經安裝的瀏覽器同時用嗎？

可以。可攜版有自己獨立的資料目錄，和系統裡安裝的版本互不干擾，兩者能同時執行。

這個專案收費或者帶廣告嗎？

不收費也不帶任何推廣。建置腳本只做解包、整合 Chrome++、注入、壓縮四件事，不改首頁、不預裝擴充、不夾帶任何私貨，原始碼遵循 MIT 授權條款並全部公開。

Windows SmartScreen 或 Defender 提示風險，還能用嗎？

SmartScreen 的信譽是依檔案慢慢累積的，GitHub Release 上剛發佈的資源經常顯示「未知」。Defender 也可能因為 Chrome++ 注入 version.dll（一種 DLL 側載手法）而啟發式誤報。本專案的建置腳本、工作流程與完整日誌都在 GitHub 公開，壓縮檔由 GitHub Actions 產出並附帶 SHA256；介意的話可以依倉庫說明在本機自行建置。仍不放心就不要下載，這裡不強迫任何人使用。

可以登入 Google / Microsoft 帳號並使用同步嗎？

可以。使用者資料在可攜目錄的 Data 資料夾裡，書籤、密碼、擴充功能的同步行為和安裝版一致。注意：放在公用或共用電腦上的可攜設定目錄裡同樣含有這些憑證，請像對待其他敏感資料一樣保管整個資料夾。

能放在 USB 隨身碟或拷到另一台電腦用嗎？

可以。解壓縮到任何有寫入權限的位置（USB 隨身碟、外接硬碟、另一台電腦）即可，資料都在程式同級目錄。部分安全軟體可能攔截可移除式媒體上的可執行檔；若被攔，先把資料夾複製到本機磁碟再執行。
